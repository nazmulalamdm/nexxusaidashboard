TecknowPoint AI Infrastructure Dashboard

A comprehensive Next.js 14/15 Admin & Telemetry Dashboard engineered for LLM Gateway orchestration, token telemetry analytics, and distributed cluster monitoring.

Version 1.0.0 Next.js 15+ Tailwind CSS 3.4+ TypeScript

1. Introduction

Thank you for choosing TecknowPoint AI Infrastructure & Gateway Telemetry Dashboard. This template is crafted specifically for AI engineers, SaaS founders, and cloud platform architects requiring clean operational monitoring over AI Gateway proxies, token burn, P95 latency spikes, and GPU node clusters.

Built completely without heavy bloated UI frameworks, it utilizes clean modular React components, native Tailwind utility architecture, and modern Lucide iconography.

2. Key Features

  • Modern Enterprise Stack: Next.js App Router architecture with strict TypeScript definitions.
  • AI Gateway Telemetry: Dedicated views for model request dispatching, P95 latency graphs, TTFT (Time To First Token), and stream drop rates.
  • Token Telemetry & Burn Metrics: Deep monitoring table detailing model routes (GPT-4o, Claude 3.5 Sonnet, Llama-3-70B), token consumption, and cost estimates.
  • Tailwind CSS Theming: Fully styled with modern dark aesthetics, customized accent color tokens (#7367f0), and CSS variables.
  • Zero Hydration / Console Errors: Production-tested components guaranteeing 0 console warnings or layout shifts.
  • Container Ready: Multi-stage Dockerfile and docker-compose.yml ready for instant deployment on Render, AWS, or Railway.

3. System Requirements

  • Node.js: Version 18.18.0 or later (Node 20+ LTS strongly recommended).
  • Package Manager: npm (v9+), yarn, pnpm, or bun.
  • Terminal: Bash, Zsh, or PowerShell.

4. Installation & Setup

Follow these steps to run the template locally on your machine:

Step 1: Extract Files

Extract the downloaded ZIP package to your desired project directory.

Step 2: Install Dependencies

Open your command line in the project folder and execute:

npm install

Step 3: Environment Setup

Copy the sample environment configuration:

cp .env.example .env.local

Step 4: Launch Dev Server

npm run dev

Open http://localhost:3000 in your web browser to view the live dashboard.

6. Production & Docker

Standard Production Build

To compile optimized production assets:

npm run build
npm run start

Docker Deployment

Build and run the standalone container with Docker:

# Build the Docker image
docker build -t tecknowpoint-ai-dashboard .

# Run container on port 3000
docker run -d -p 3000:3000 --name ai-dashboard tecknowpoint-ai-dashboard

7. Customization Guide

Changing Accent Colors

Open tailwind.config.ts to adjust the core brand accents. Replace the purple accent with your corporate branding:

// tailwind.config.ts
theme: {
  extend: {
    colors: {
      brand: {
        500: '#7367f0', // Change this hex code to your preferred color
        600: '#5e50ee',
      }
    }
  }
}

Updating Logo & Brand Name

To update the dashboard title and initials, navigate to src/components/layout/Sidebar.tsx and modify the brand banner and typography.
