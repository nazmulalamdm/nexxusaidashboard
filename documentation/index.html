NexusAI - Next.js 15 AI Dashboard Documentation

Official technical manual and architecture guide for NexusAI — a high-performance, DevOps-ready Admin Dashboard built with Next.js 15 (App Router), Tailwind CSS, Recharts, and Docker containerization.

Project Tech Stack

  • Framework: Next.js 15 (App Router, Turbopack, Standalone output)
  • Language: TypeScript
  • Styling: Tailwind CSS, PostCSS
  • Visualizations: Recharts
  • CI/CD & DevOps: GitHub Actions Workflow, Multi-Stage Dockerfile, Docker Compose

3. Getting Started (Development Setup)

Ensure you have Node.js 20+ installed on your system.

# 1. Open your terminal in the source code folder
cd source-code

# 2. Install dependencies cleanly
npm install

# 3. Launch development server
npm run dev

Navigate to http://localhost:3000 in your browser to view the application.

4. Docker Container Deployment

Deploy the application in an isolated production environment using Docker Compose:

# Build the image and start the container
docker compose up -d --build

# Inspect execution logs
docker compose logs -f

# Shut down the container
docker compose down

Access the containerized instance at http://localhost:3000.

5. Production Build Verification

To compile the project and generate the standalone production artifact:

npm run build
npm start
